## Description:
BATMood Games is a service that hosts a variety of quick and simple games to play with a party of friends. Inspired by Jackbox.

## Install Guide:
1. Clone
   ```
   git clone git@github.com:Tobber55/p05_BATMood.git
   ```
2. Enter
   ```
   cd p05_BATMood
   ```
3. Start and activate a virtual environment
   ```
   python3 -m venv venv
   ```
4. Install requirements
   ```
   pip install -r requirements.txt
   ```

## Launch Codes:
1. Run the app
   ```
   python3 app/__init__.py
   ```
2. Once done, deactivate the venv
   ```
   deactivate
   ```
